## Irudiak

Argazki **guztiak** `irudiak/` karpeta bakarrean doaz. Markdowneko estekak erlatiboak dira (`irudiak/...`), beraz GitHubera igotzean automatikoki agertzen dira.

- Datu-baseetako 8 argazkiak **jada sartuta** daude.
- Falta diren argazkiak jartzeko: gorde zure kaptura `irudiak/` karpetan, **esteka-izen zehatzarekin**, eta dokumentuan bakarrik agertuko da (testurik gabe). Zein fitxategik zer behar duen jakiteko, ikus [`irudiak/_IRUDIEN-ZERRENDA.md`](irudiak/_IRUDIEN-ZERRENDA.md).
